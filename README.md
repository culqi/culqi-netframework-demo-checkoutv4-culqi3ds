# Demo Culqi para .NET Framework

## Configurar credenciales de prueba

Antes de ejecutar el demo, reemplaza los marcadores de configuración en los controladores y en `DemoCulqi/js/config/index.js` con tus propias credenciales Culqi de prueba:

- `INSERTE_SU_LLAVE_PUBLICA`: llave `pk_test_`.
- `INSERTE_SU_LLAVE_PRIVADA`: llave `sk_test_`.
- `INSERTE_SU_RSA_ID`: identificador RSA de tu configuración.
- `INSERTE_SU_LLAVE_RSA`: llave pública RSA correspondiente.

No incluyas llaves en commits. El demo puede realizar solicitudes reales a la API de Culqi.
